## Project & Sprint Plans

- **PROJECT_PLAN.md** (PROJECT-PLAN-001) — Master project plan, 8-sprint roadmap, Phase 0–4, Layer 1/Layer 2 distinction, risk register
- **SPRINT_SUCCESSION.md** (SPRINT-PLAN-001) — All planned sprints with deliverables, gate criteria, dependencies, success metrics
- **SPRINT_1_DETAILS.md** — Detailed Sprint 1 work items, acceptance criteria, effort estimates, blockers/risks

## Usage

- Program Manager uses plans to structure backlog and sprint execution.
- Chief Engineer uses plans to enforce technical and governance gates.
- Specialist agents execute plan-defined activities and produce evidence.
- HITL reviewers use plan checkpoints for approvals and corrective actions.
- Developers use Sprint Details to understand work items and acceptance criteria.
