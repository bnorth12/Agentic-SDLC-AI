# Agentic Governance Policies

This folder defines mandatory governance policies for how the agentic engineering organization operates.

## Purpose

These policies provide the enforceable rules used by agents and human-in-the-loop (HITL) reviewers to manage work, control risk, maintain traceability, and achieve a reliable system development lifecycle (SDLC).

## Policy Set

- systems-engineering-management-policy.md
- project-management-policy.md
- requirements-management-policy.md
- architecture-development-policy.md
- configuration-management-policy.md
- data-management-policy.md

## How Policies Are Used

- Agents apply these policies during planning, execution, reviews, and handoffs.
- Review boards check policy conformance before approval.
- HITL reviewers use policy checkpoints to approve, reject, or request rework.

## Enforcement Model

- Mandatory statements use "shall" and are required unless formally waived.
- Policy exceptions require explicit justification and Chief Engineer plus Program Manager approval.
- Violations are logged in the decision log and tracked as corrective work items.
