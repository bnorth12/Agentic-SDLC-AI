# Roadmap

## Current Repo State

The repository has moved beyond the original Phase 0 baseline. The current codebase already includes:

- A working LangGraph supervisor with governance hooks and checkpoint snapshots
- 12 implemented agents, including the expanded security, safety, compliance, integration, QA, operations, and maintenance roles
- Governance gates for requirements, architecture, implementation, and deployment
- WorkPackage queue/resume support plus KPI tracking scaffolding
- Integration and end-to-end tests covering the expanded workflow

The roadmap below is the forward-looking plan from this point onward.

## Phase 1 — MVP Foundation

- Establish shared state schema
- Implement supervisor skeleton
- Add 3-4 core agents (requirements, architecture, development, verification)
- Add HITL pause/approve hooks

## Phase 2 — SDLC Expansion

- Add systems engineering and safety/security/reliability agents
- Add configuration management workflows
- Add review board subgraphs and governance checkpoints
- Introduce artifact traceability views

## Phase 3 — Persistent Multi-Run Operations

- Add robust checkpointing and recovery
- Add long-horizon planning and work package queues
- Add metrics and observability dashboards

## Phase 4 — Advanced Capabilities

- Multi-model routing and role-based model policies
- Risk-aware planning and automated trade studies
- Deeper compliance evidence generation
- Scalable multi-team orchestration
