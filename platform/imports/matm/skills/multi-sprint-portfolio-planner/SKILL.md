# Multi-Sprint Portfolio Planner Skill

## Purpose
Build a governed multi-sprint structure that balances capability delivery and system integrity.

## Inputs
- sprint plans and roadmap artifacts
- architecture/design prerequisites

## Procedure
1. Build dependency graph across sprint epics and requirements.
2. Identify critical path and architecture runway constraints.
3. Score risk concentration and carryover exposure.
4. Propose staged portfolio execution gates.

## Outputs
- Portfolio staging plan with dependency-aware sequencing.
- Governance checkpoints and risk mitigation schedule.
