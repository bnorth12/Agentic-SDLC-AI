# Verification Coverage Planner Skill

## Purpose
Drive complete, auditable verification linkage for each governed requirement.

## Inputs
- Requirements/
- Tests/
- verification strategy references

## Procedure
1. Map requirements to verification artifacts and methods.
2. Identify requirements with missing or weak verification evidence.
3. Prioritize verification debt by severity and sprint relevance.
4. Produce verification-ready backlog actions.

## Outputs
- Verification coverage ratios and missing-link findings.
- Prioritized remediation actions for verification readiness.
