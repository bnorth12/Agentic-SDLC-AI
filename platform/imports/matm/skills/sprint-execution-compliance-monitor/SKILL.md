# Sprint Execution Compliance Monitor Skill

## Purpose
Continuously detect and contain governance drift during active sprint work.

## Inputs
- active sprint planning and issue artifacts
- latest governance review outputs

## Procedure
1. Evaluate KPI and severity deltas during sprint execution.
2. Detect new traceability and verification gaps.
3. Flag blocker aging and unresolved governance risk.
4. Recommend immediate containment actions.

## Outputs
- In-sprint compliance trend report.
- Corrective actions for near-term stabilization.
